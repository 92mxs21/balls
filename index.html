balls

Fabric + mod setup for Minecraft 26.3, in one file.

Download run.cmd keep it next to install-mods.ps1 and mods.json
Windows may warn you. SmartScreen flags anything downloaded as a file rather than a known app. Choose More info → Run anyway. This is a plain, readable batch file — open it and check.
  1. Put run.cmd, install-mods.ps1 and mods.json in the same folder.
  2. Double-click run.cmd.
  3. It finds your Fabric profile (installing one if it is missing) and pulls Sodium, Fabric API, Lithium, FerriteCore and friends straight from the Modrinth API.
  4. Every download is checked against the SHA-512 Modrinth publishes.
  5. Open the launcher, pick the fabric-loader-26.3 profile, play.
